# Voxel

Voxel terrain viewer for the Slovenian national LiDAR survey, rendered in the browser with WebGPU.

## Live demo

**https://voxel-playground.ddns.net**

The demo runs on a free dynamic-DNS address and a home machine, so it may go offline without notice. It needs a browser with WebGPU support (Chrome or Edge on desktop).
